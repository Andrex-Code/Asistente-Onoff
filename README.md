# Asistente ONOFF

Extensión de Chrome/Edge basada en el traductor de TryController.

## Funciones

- Traducir selección PT-BR → Español.
- Falar selección Español → PT-BR y reemplazar el texto.
- Mejorar texto seleccionado y reemplazarlo usando trato obligatorio de **usted**.
- Cargar y traducir audios.
- Abrir 17 plantillas de Bitrix24.
- Guardar seguimientos locales con nombre y enlace de tarea.

## Instalación

1. Descargue el repositorio.
2. Abra `edge://extensions` o `chrome://extensions`.
3. Active el modo desarrollador.
4. Seleccione **Cargar descomprimida** y elija esta carpeta.

## Backend

Despliegue el repositorio en Vercel y configure `OPENAI_API_KEY`. Luego abra las opciones de la extensión y registre la URL del despliegue.

## Respaldo del proyecto anterior

La aplicación anterior de base de conocimiento se conserva en la rama `legacy-base-conocimiento`.
