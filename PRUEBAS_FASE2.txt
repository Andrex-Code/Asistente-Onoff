========================================================
  PLAN DE PRUEBAS - FASE 2: Panel Admin + ChatWidget
========================================================

PREPARACION:
  1. Backend:  cd backend && uvicorn main:app --reload --port 8000
  2. Frontend: cd frontend && npm run dev
  3. Abrir http://localhost:5173

========================================================
PRUEBA 1 - Navegacion Header
========================================================
[ ] Verificar que el Header muestra dos links: "Inicio" y "Admin"
[ ] Click en "Admin" -> navega a /admin
[ ] Click en "Inicio" -> navega a /
[ ] El link activo tiene fondo semi-transparente
[ ] El titulo "Asistente de Procesos ONOFF" sigue visible

========================================================
PRUEBA 2 - Panel Admin: Toggle del chatbot
========================================================
[ ] Ir a /admin
[ ] Verificar que aparece "Panel de Administracion"
[ ] Verificar que el switch muestra "Activar Asistente Inteligente"
[ ] Verificar que el switch inicia en OFF (gris)
[ ] Click en el switch -> cambia a verde (ON)
[ ] Verificar en backend: GET http://localhost:8000/config
    debe retornar {"chatbot_enabled": true}
[ ] Click de nuevo -> vuelve a gris (OFF)
[ ] Verificar en backend: GET http://localhost:8000/config
    debe retornar {"chatbot_enabled": false}

========================================================
PRUEBA 3 - Panel Admin: Subir PDF
========================================================
[ ] En /admin, verificar que aparece seccion "Subir documento PDF"
[ ] Click "Seleccionar PDF" -> se abre selector de archivos
[ ] Seleccionar un archivo PDF de prueba
[ ] Verificar que muestra mensaje de exito con nombre y fragmentos
[ ] Verificar que el documento aparece en la lista de abajo
[ ] Intentar subir un archivo que NO sea PDF (ej: .txt)
    -> debe mostrar error "Solo se permiten archivos PDF"

PRUEBA 4 - Panel Admin: Lista de documentos

PRUEBA 8 - API Backend directa (opcional, con curl o Postman)
========================================================
[ ] GET  http://localhost:8000/config
    -> {"chatbot_enabled": false}

[ ] POST http://localhost:8000/config
    Body: {"chatbot_enabled": true}
    -> {"chatbot_enabled": true}

[ ] POST http://localhost:8000/upload-pdf
    Form-data: file=@archivo.pdf
    -> {"message": "PDF procesado correctamente", "document": {...}}

[ ] GET  http://localhost:8000/documents
    -> {"documents": [...]}

[ ] DELETE http://localhost:8000/documents/{id}
    -> {"message": "Documento eliminado correctamente"}

[ ] POST http://localhost:8000/search
    Body: {"query": "palabra"}
    -> {"query": "palabra", "total_results": N, "results": [...]}
