# 0.21.2 — aviso de éxito de un segundo

Después de confirmarse el resultado del servidor, la interfaz de confirmación se cierra si no quedan confirmaciones, envíos pendientes o fallos. Se muestra Tipificación creada durante 1000 ms y se retira sola. Se eliminan los avisos flotantes persistentes de estado/radicado; el enlace se conserva en el historial. El botón flotante de consulta solo existe cuando hay registros accionables. La consulta de estados es local, sin nuevas llamadas IA ni escrituras Bitrix.

El historial de consulta manual tiene Cerrar historial cuando no exige confirmar una creación; encabezado con color explícito. Un fallo conserva su mensaje e interfaz de revisión. No se ofrece aplazar una confirmación pendiente. La protección de cierre, TC, fechas, orden etapa-completar e idempotencia no cambia. Pruebas de flujo, cola y temporizador en Chromium sintético; sin cerrar chats reales ni crear tareas durante esta versión.
