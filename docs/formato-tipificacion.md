# Formato de descripción de tipificación

La creación y la edición del borrador usan el mismo formateador determinista: marca PRUEBA, encabezado TIPIFICACIÓN DEL CHAT, etiquetas Motivo/Gestión/Resultado en negrita y párrafos separados. El pie se limita a Conversación: iKono (teléfono), íntegramente en negrita. Se elimina del texto visible el bloque de TC/día/tipificación/detalle/URL y referencia genérica. Los campos personalizados y la trazabilidad interna permanecen. El teléfono se toma del contexto validado, sin un número específico codificado. No cambia el contenido clínico ni de gestión: no inventa acciones o resultado.

Se utiliza BBCode para los rótulos, conservando texto libre y escapando corchetes ajenos. Pruebas de resumen en una línea, Markdown y flujo de preparación/edición/creación/completar: 20 aprobadas. No se editaron tareas existentes. Cambio del servidor, sin requerir reinstalar extensión.
